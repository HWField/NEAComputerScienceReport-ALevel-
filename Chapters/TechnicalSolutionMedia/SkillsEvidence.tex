\section{Skills Summary Table}
This chapter provides a comprehensive breakdown of the technical skills demonstrated throughout this project, organized according to AQA assessment criteria Groups: A, B, and C.

The majority of requirements are met by the backend SimulationAPI project, which contains the core logic, data models, algorithms, and client-server communication. The frontend project implements a subset of skills related to client-side state management (largely replicating the main database models) and API interaction which have been identified where appropriate.

All locations evidenced are clickable references to specific files within the source code Appendix allowing for easy verification of the implemented skills. Alternatively all code can be found listed in Appendix~\ref{appendix:code} which additionally contains a full directory listing .
